# Data

The three benchmark datasets are public:

## C-Dataset / F-Dataset

Standard drug–disease association benchmarks (see Gottlieb et al., *Mol. Syst. Biol.* 2011; Hassanali Aragh et al., *Brief. Bioinform.* 2024).

- Drug features (category, condition, description, mechanism of action, pharmacodynamics, SMILES, targets): DrugBank
- Disease features (description, pathway names, slim mapping): CTD
- Identifiers standardized to DrugBank IDs (drugs) and OMIM/MeSH IDs (diseases)

## DDCD (Drug–Disease Comprehensive Dataset)

Curated from CTD; 1,410 drugs, 1,573 diseases, 42,200 verified associations.

## Required directory layout

```
data/
├── C-Dataset/
│   ├── Features/drug_features_C.csv
│   ├── SimilarityMatrices/          # per-modality similarity matrices
│   ├── Mapping/mapping_C.csv        # full ID mapping
│   ├── Mapping/mapping80_C.csv      # 80/20 mapping (leak-prone source, ablation only)
│   └── Splits/                      # split manifests (generated by data_split.py)
├── F-Dataset/   (same structure)
└── DDCD/        (same structure)
```

## Pre-computed artifacts (published with the repository)

- MoLFormer embeddings (768-d per drug) and cosine similarity matrices: `code/results/molformer/`
- Split manifests and per-seed results: `data/*/Splits/` (generated) and `results/`
- The largest DDCD evaluation files exceed GitHub's per-file limit and are hosted on Zenodo (DOI: 10.5281/zenodo.21883418); restore them with the download script provided in the repository.

## Notes

- F-Dataset contains 591 drugs in the harmonized mapping (earlier releases reported 592–593); all results in the manuscript use the corrected entity set.
- Feature construction must use the leak-safe neighbor source (`--neighbor-source r2train`) for the unified protocol; the `mapping80` source is provided only for the feature-source ablation.

## CTD therapeutic subset (case study known set)

`DDCD/Mapping/mapping_therapeutic.csv` = 13,579 CTD therapeutic-curated associations
(DirectEvidence containing "therapeutic") restricted to DDCD entities: diseases by exact
MeSH ID, drugs by normalized-name matching against `drugsInfo.csv` (salt-suffix stripping
plus a curated synonym list). Reproduce with `code/build_therapeutic_mapping.py` (v1 exact)
and `code/match_therapeutic_v3.py` (final) after placing the official CTD file at
`data/ctd_raw/CTD_chemicals_diseases.csv.gz` (https://ctdbase.org/reports/CTD_chemicals_diseases.csv.gz).
The name-matching audit is `data/ctd_raw/therapeutic_audit.csv`.
